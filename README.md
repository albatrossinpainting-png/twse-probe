# twse-probe

一個問題，一支程式：**從 GitHub Actions（Azure IP）打得通證交所、櫃買、集保嗎？**

## 為什麼要問

台股有幾個資料端點只公告「現在」，不給歷史——停資停券預告、除權息預告、
集保戶股權分散。今天沒抓，那一天的資料就永遠拿不回來了。

家用電腦不會 24 小時開機。GitHub Actions 免費又有 cron，是最自然的備援，
但**證交所常擋資料中心 IP**，而 Actions 跑在 Azure 的 IP 段上。

蓋任何東西之前先確認這件事。做法是**同一支程式跑兩次**：

    本機（家用 IP）            → 基準線，已知可通
    GitHub Actions（Azure IP） → 要驗證的

兩邊結果一比就知道是不是被擋。**這是受控比較，不是猜測。**

## 本機基準線（2026-09-06，IP 118.168.218.91）

| 端點 | 帶 UA | 不帶 UA |
|---|---|---|
| TWSE 停資停券預告 `BFI84U` | ✓ 200，76 列 | ✓ 200，76 列 |
| TWSE 除權息預告 `TWT48U` | ✓ 200，82 列 | ✓ 200，82 列 |
| TPEX 暫停融券賣出 `tpex_margin_trading_term` | ✓ 200，70 筆 | ✓ 200，70 筆 |
| TPEX 除權息預告 `tpex_exright_prepost` | ✓ 200，133 筆 | ✓ 200，133 筆 |
| TDCC 集保股權分散 `getOD.ashx?id=1-5` | ✓ 200，2.36 MB | ✗ TooManyRedirects |

**五個端點全通。** 集保不帶 User-Agent 會被丟進轉址迴圈，所以正式程式一律帶。

## 怎麼跑

Actions 分頁 → 左邊選 `probe-endpoints` → **Run workflow**。約一分鐘。

輸出的第一行是這台 runner 的對外 IP，那是比對時最重要的一行。

## 怎麼判讀

* **五個全通** → GitHub Actions 可以當備援，繼續往下蓋
* **本機通、這裡不通** → IP 被擋，這個方案不能用，要換別的（自架、固定開機…）
* **兩邊都不通** → 是端點改版或壞掉，不是 IP 問題，先修爬蟲

## 刻意的設計

* **不依賴任何專案程式碼**，只用 `requests`，整支複製到哪裡都能跑
* **每個端點打兩次**，一次帶瀏覽器 User-Agent、一次不帶——被擋的原因是 IP
  還是 UA，這樣才分得出來
* **不只看狀態碼**。交易所被擋時常常還是回 200，內容是一頁 HTML 錯誤頁，
  所以要驗內容的形狀，並把開頭幾個字印出來
* **每次請求間隔 5 秒**。全程只打 10 次，寧可慢也不要把 IP 弄進黑名單
